How the 2D boundary is drawn (and why there's no dimensionality reduction)

A common assumption is that the picture above is a 2D projection of something high-dimensional. It isn't — and the distinction matters. The inputs are genuinely 2D (each point is an (x, y) coordinate), so we can draw the model's decision surface directly, with no PCA, t-SNE, or any reduction:

1. Lay a 56×56 grid of (x, y) points over the plane. 2. Run every grid point through the trained MLP and take the softmax probability of class 1. 3. Shade each pixel by that probability (blue→white→red); the black line is the P=0.5 decision boundary (marching squares). 4. Overlay the actual train / test data points.

So what is high-dimensional here is the optimizer's working space, not the picture. The network has thousands of weights; the gradient covariance the filter tracks lives in that thousand-dimensional parameter space, and the filter keeps only its top-k eigendirections. The 2D plot is just a faithful readout of the function those weights compute — it lets us see the consequence of the filter's high-dimensional projection (a smooth, noise-resistant boundary) without ever projecting the picture itself. This is why a true 2D-parameter toy (e.g. the Rosenbrock demo) can't show the effect, but a 2D-input network with thousands of weights can.
