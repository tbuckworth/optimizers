## Official API check

The serialization guidance supports exact owned storage checks and explicit
restricted CPU loading; shared backing storage can otherwise exceed visible
tensor sizes. The buffer API requires releasing non-copying views before closing
or resizing. These are API properties, not an empirical storage certificate.
