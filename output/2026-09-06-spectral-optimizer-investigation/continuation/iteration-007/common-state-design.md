# Current-policy-state conditional 2x2 delivered-gradient response

Codex, Spectral Optimizer Investigation, 6 September 2026.
Evidence status: **prospective proposal; no new outcomes**.
Supersedes the deferred whole-policy extension for design review only.
No dataset access, pilot or neural execution is approved here. The later
[component decision](implementation-decision.md) permits only scoped CPU engineering.

## Question and limited estimand

On states generated by the current32 policy, how do changing the delivered
gradient direction and its norm separately affect the next AdamW displacement
and immediate clean/noisy loss? Existing own-trajectory results cannot answer
this because parameters, moment histories and selected exposure differ.

The factors are two gradient-derived directions and two gradient-derived input
norms, not general direction/magnitude mechanisms. The primary outcome is
one-step change in fixed auxiliary-clean mean CE,
conditional on the captured state and probe. The corresponding noisy-training
probe response tests a possible immediate clean/corrupt tradeoff. Neither is
long-run mediation, semantic denoising, or an untouched generalization estimate.
Actual-step geometry is explanatory measurement, not a substitute for loss.

Raw/lagged/restored source states and clean-data training are deliberately absent.
Conclusions must therefore say **current-policy-state conditional response**.

## Five one-step branches and a zero-input reference

From an owned clone of a complete anchor, recompute the same raw float32 batch
gradient g. Copy the previous basis, then ingest g exactly once into a cloned
observer. Let c be native current-basis projection, l native previous-basis
projection, and nc/nl their float64-accumulated Euclidean norms. Missing bases
have the canonical identity action, not zero projection. Freeze the same c/l
for all branches; branch order must not alter candidate construction.

| Branch | Delivered gradient | Role |
|---|---|---|
| raw | g | Unfiltered next step with the same existing filtered-history moments |
| current | c | Current direction, current norm; source-policy replay control |
| lagged | l | Previous direction, previous norm |
| restored | `(nc/nl) l` | Previous direction, current norm |
| reciprocal | `(nl/nc) c` | Current direction, previous norm |
| zero reference | exact zeros, never None | Existing-moment motion plus decay with no new gradient input |

For nonzero directions, construct the scaled vector as float64 unit direction
times float64 target norm and cast once to native float32. The ratios above
define the mathematical gradients, not permission to evaluate 0/0. This is a
standalone arithmetic contract; no bitwise equivalence to I6's scaled arms is
assumed. Native c/l and raw are delivered unchanged. Check
the actual assigned .grad norm and normalized-direction relative errors <=1e-6.
Zero target yields an exact zero gradient and still takes an AdamW step.
Positive target with zero direction is explicitly undefined. Zero is exact
float64-accumulated norm zero; a tiny positive norm is not changed to zero.

| nc | nl | restored | reciprocal | Interpretation |
|---|---|---|---|---|
| positive | positive | defined normalized l times nc | defined normalized c times nl | Full grid, subject to numerical gates |
| zero | positive | exact zero | undefined positive-target/zero-direction | Retain cells; incomplete grid |
| positive | zero | undefined positive-target/zero-direction | exact zero | Retain cells; incomplete grid |
| zero | zero | exact zero | exact zero | Identical zero inputs; no direction/norm leverage |

Zero-vector angles/ratios are null with reasons. A positive target lost through
native underflow, nonfinite rescaling, invalid metadata or another failed
numerical invariant stops for review; do not relabel these as scientific nulls.
Any contrast depending on an undefined cell is undefined. A per-time aggregate
requires all three predeclared primary bundles defined; otherwise it is null
with the full mask, never an available-case average. Retain every anchor.

Each valid branch reloads the identical parameters and full AdamW state, assigns
only its prescribed gradient and takes **exactly one** AdamW step. No branch
trains onward or modifies the source trajectory. The raw branch is not a
counterfactual raw-AdamW training history. Full anchors are saved during source
training; scientific branch evaluation begins only after all primary source
trajectories finish (the sensitivity bundle has its own completion boundary).
The zero reference still advances AdamW's counters and decays moments. Its
contrast with each other branch is a finite response to changing the current
input at fixed history, not an additive decomposition of a training trajectory.

## Measurements and mandatory comparisons

Persist raw/c/l and actual delivered gradients; actual native before/after
parameter tensors and bindings (not just hashes or reconstructed endpoints);
actual native post-step first/second moments and counters for every valid branch;
full displacement `delta = float64(theta_after) - float64(theta_before)` from
native saved parameters; and `delta_data = delta + lr * wd * float64(theta_before)`.
The latter subtracts the nominal decoupled decay term, not floating-point
roundoff, historical momentum or a separately executed decay-only update.
Never first subtract in float32 and then cast. Report both quantities.
Measure their norms, pairwise cosines and within-anchor vector differences.

Evaluate four losses before and after each valid branch:

1. the actual noisy training minibatch;
2. the fixed training probe with its corrupted labels;
3. the same training probe with clean labels;
4. the full fixed auxiliary-clean pool (**primary outcome**) and its ten chunks.

For loss diagnostics, convert saved native parameters and the fixed normalized
float32 inputs to CPU float64 and evaluate the same network/mean CE. This
defines the measurement function explicitly and reduces cancellation from
subtracting native float32 losses; it is not float64 training. Save each before
and after value as well as the signed difference. Use eval-mode Linear–ReLU–
Linear, parameter order `0.weight`, `0.bias`, `2.weight`, `2.bias`; integer
labels; unweighted, unsmoothed CE over all examples. Sum loss/gradient in fixed
500-example chunks for the auxiliary pool, then divide by 5,000; shorter probes
are one chunk. Convert already normalized float32 inputs; never repeat pixel
normalization in float64. Also save native GPU-float32 before/after losses as
secondary concordance checks, on clones with the same ordering and chunk sizes.
Disagreement restricts claims about native loss, not the defined float64
measurement. Compute the gradient of this
same float64 function at theta_before and its dot product with full delta;
report the finite-loss minus first-order prediction residual. Also report the
dot product with delta_data, without calling it a separate finite-loss result.

For each scalar outcome Y (especially auxiliary-clean delta CE), always show:

- total ordering contrast: `Y(lagged) - Y(current)`;
- direction at current norm: `Y(restored) - Y(current)`;
- direction at previous norm: `Y(lagged) - Y(reciprocal)`;
- norm at current direction: `Y(current) - Y(reciprocal)`;
- norm at previous direction: `Y(restored) - Y(lagged)`;
- interaction: the previous-direction norm contrast minus the current-direction
  norm contrast; do not assume an additive direction-plus-magnitude model;
- all four projected-branch contrasts against raw.
- all five nonzero-policy branch contrasts against the zero-input reference
  (a nominally nonzero policy can deliver zero at a degenerate anchor).

Record factor leverage per anchor: nc, nl, ratio/difference, unit-direction
cosine/distance, and every actual delivered-vector distance. Direction distance
<=2e-6 or relative norm separation `abs(nc-nl)/max(nc,nl)` <=2e-6 is below the
chosen delivery-gate resolution for that factor, not evidence of scientific
equality. Keep numeric contrasts but suppress factor-level interpretations there.
Both-zero and undefined levels have no corresponding factor leverage.

For delta CE, negative means the first named branch lowers that probe loss
more. Show all 12 primary anchors, with four sensitivity anchors separately.
At each fixed time, report the three primary bundle values and descriptive
mean/range. Do not pool times as independent samples or hide undefined masks.
No p-values, equivalence, sign-frequency or practical-effect threshold claims.

## Outcome-to-next-action rule

Precedence is numerical validity, defined cells, factor leverage, complete
contrasts, then interpretation. Always report the full signed table before
choosing a next question. Differences too small relative to the independently
measured audit discrepancies receive no resolved-sign claim. This is numerical
ambiguity, not an equivalence test or a statement about probe sampling error.
Record exact sign counts only for the named states; never a population frequency.

| Observed structure | Permitted update to the hypothesis | Next action after the fixed study |
|---|---|---|
| Resolved interaction in any leverage-qualified anchor | The finite two-factor response is nonadditive at that anchor | Report where it occurs; no additive direction/magnitude mediation claim |
| All 12 anchors have leverage and resolved, same-signed direction contrasts at both input norms | Observed concordance only on this fixed grid | A raw-AdamW source-state comparison becomes the next candidate for a new design, not automatic execution |
| Sign or ordering changes across times/bundles/probes | The immediate mechanism is state/probe dependent | Stop any universal local-direction explanation; retain the full profile |
| Incomplete leverage, unresolved signs, or failure of that exact 12-anchor concordance | The stated source-transfer prioritization rule is not met | Do not prioritize the raw-state extension from this result; report conditional limitations without more local seeds |
| Numerical audit or source-control replay fails | No interpretable scientific comparison from affected execution | Preserve partial artifacts and diagnose before any new execution |

Mixed structures can coexist and must be reported together; heterogeneity takes
precedence over a broad direction interpretation. No outcome in this study
authorizes reciprocal whole-training experiments. The concordance rule is a
research-prioritization heuristic, not evidence of stability or a statistical
test; no general sign or equivalence follows even if it is met. Finish exactly
the three primary trajectories and separately planned sensitivity trajectory,
with no replacement seeds or extended windows. A favorable local result never
automatically authorizes a long-run test or production change.

## Complete state and audit requirements

Anchor schema must include model parameters/buffers/order/modes/gradient-null
mask; full optimizer state/groups/order; all observer fields except live-object
aliases; Python, NumPy and Torch CPU/CUDA RNG; next-batch pointer and indices;
plan/probe/label/data identities; phase t; source hashes and numerical environment.
Observer S intentionally remains CPU float64 while V/mean have native placement.
Load primitive/tensor-only payloads with explicit `weights_only=True` and CPU
map_location, then restore recorded devices. Never deserialize arbitrary objects.

Mandatory checks before neural launch: independent clones/no storage aliases,
exact schema and tensor round-trip, parameter-order binding, regenerated batch
gradient/candidates, observer count increment once, optimizer step counters
increment once, source current-branch replay matches the actual next source
update and moments, branch-order independence, and probes/capture leave the
complete live state and RNG unchanged. Replay identity is required on the
same recorded software/hardware path, not promised across CPU/GPU or releases.
The replay witness must come from the actual live source step immediately
after capture: raw/delivered gradient, before/after parameter, optimizer and
observer bindings. A witness produced by replay itself is circular and invalid.
Do not attach capture to I6's post-step measurement hook. Update 101 is the
shared raw-warmup endpoint; later anchors are endogenous current-policy states.

An independent auditor must reconstruct branch arithmetic, displacement and
loss contrasts from raw anchors/results without importing the producer's
aggregation. Cross-device numerical comparison uses prospectively specified
tolerances, separate from exact same-platform reload/replay gates. A fresh
bundle is a sensitivity rerun, not a replacement for independent numerical audit.
