preserve useful prior knowledge while changing which new associations are
acquired. It supported leading with the all-seed corruption-protection and
same-exposure improvements, retaining relative patched-image protection, then

equating these with an alignment defense or covariance-mediated endpoints.

competence, including rare requirements, response quality and coverage. A frozen
parent distinguishes preserved behavior through inactivity from preservation
while useful learning occurs. Main uses this as a **future efficacy contract**,
not a requirement to run another experiment before reporting the current paper.
Main additionally distinguishes theory limitations from absence of theory,
gradient semantics from semantic guarantees, and adapter from covariance spectra.
